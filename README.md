# DumpableFood
Allows loose bulk food and agricultural products to be dumped onto the terrain as stockpiles and mined back with excavators.

### Dumpable Loose Food Products
* Potato
* Corn
* Wheat
* Soybean
* Sugar Cane
* Canola
* Poppy
* Sugar
* Animal Feed

### Texture Note
Terrain stockpiles use Captain of Industry's terrain material textures rather than silo/product pile materials directly, as the game handles terrain rendering and product pile rendering through separate material types. Because of this, colors and surface textures are approximations using built-in terrain assets rather than a 1:1 match to silo textures.
